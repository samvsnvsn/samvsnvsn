# Arteloux Optimization

Online material-layout optimization as a service for small businesses, workshops,
makers and manufacturers that cut physical materials and do not want, or cannot
justify, industrial nesting/CAD/CAM software.

**Status:** project definition only. No product implementation has started.

## Relationship to SOUP / SigmaNEST

Arteloux Optimization is **not** a phase of the SOUP/SigmaNEST project. SOUP is an
existing technology asset that may later provide reusable geometry/optimization
components. Arteloux has a broader commercial objective and stays separate from the
production SOUP repository until an audit determines the correct reuse/migration
strategy. Do not rename SOUP to "Arteloux Engine". Audit first.

## Development discipline

Do not start implementing the full product. In order:

1. Preserve this project definition (done: these documents).
2. Audit SOUP for reusable technology.
3. Research the current market and competitors.
4. Identify underserved customer segments.
5. Determine the smallest commercially testable MVP.
6. Only then create an implementation roadmap.
